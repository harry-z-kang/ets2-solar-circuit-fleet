# Screenshots for livery refinement

The 27 supplied screenshots already help identify mirrored coach lettering, coach logos reaching the window band, truck logos crossed by factory badges, and painted trim that breaks the design. The following views make the next corrections easier to locate on the UV maps.

## Capture set for each distinct cabin or coach body

| View | What it resolves |
| --- | --- |
| Straight left side | Logo size and placement; door handles; panel edges; stripe height |
| Straight right side | Opposite-side reading direction; mirrored text; asymmetric parts |
| Straight front | Badge and grille clearance; corner stripe continuity; bumper parts |
| Straight rear | Rear-panel layout, equipment towers, spoiler edges and seams |
| Front three-quarter from each side | Wrapping around cab corners; doors, steps and fenders |
| High rear three-quarter | Roof solar details, cab rear, spoilers and 8×4 equipment towers |
| Close-up of each problem | Exact clipping, badge overlap, texture stretching or painted accessory mismatch |

Use daylight and neutral lighting. Hide accessory pins and the configurator UI where possible. Keep the whole vehicle in frame without cropping it; fill most of the image. For trucks, detach the trailer to expose the cab rear. A close-up supplements the full view rather than replacing it.

Include the **model, cabin/body length, chassis, module version and painted-accessory choices**. Capture the same angle before and after changing a suspect accessory when practical. Example filename: `daf_xgplus_6x2_right_v04.png`.

## Priority order

1. **Coach right sides, then straight fronts/rears and high roof views:** Volvo 9700 DD, MAN Lion's Coach 13.9 m and Scania Touring 13.7 m. Existing side shots already demonstrate reversed text; front/rear/roof views will reveal the remaining mapped regions. Include the shorter coach bodies if you use them.
2. **Volvo FH5/FH6 8×4:** straight sides and close-ups where factory badges or tuning trim cross the team mark. Include a high rear view of the equipment area.
3. **Iveco S-Way, modern MAN TGX and Renault T:** straight sides plus close-ups of door, step, fender and trim boundaries visible in the supplied screenshots.
4. **New Mercedes and DAF maps:** start with one cabin per model, both straight sides and front/rear. Then repeat for the other cabins, especially low/day cabs, Actros 8×4 and DAF XF/XG/XG+ heavy versions.

One complete view set per distinct cab/body is more useful than many nearly identical three-quarter shots. These views are for checking appearance; the current Mercedes/DAF package already includes every standard SCS family and cabin listed in its [coverage guide](MERCEDES-DAF-LIVERIES.md).
